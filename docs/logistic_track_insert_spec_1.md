# logistic_track テーブル更新仕様書 (1)

---

## 概要

日本郵便からSFTP経由で取得した追跡情報CSVを解析し、`logistic_track` テーブルに書き込む。

- **対象商品**：ゆうパックのみ（ゆうパケットは将来対応）
- **実行タイミング**：毎日 13:05 / 18:05 / 23:55 にCSV取得後に実行

---

## 1. 入力ファイル定義

V6可変長フォーマット・Shift-JIS・ヘッダレコードあり（1行目はファイルヘッダ、2行目以降がデータ）。

### ヘッダレコード（1行目）

| # | 項目名 | 概要 |
|---|--------|------|
| 1 | ファイルバージョン | 固定で `60` |
| 2 | レコード件数 | ボディレコードの件数 |
| 3 | 送付対象日時（開始） | `YYYYMMDDhhmm` |
| 4 | 送付対象日時（終了） | `YYYYMMDDhhmm` |
| 5 | 予備 | |
