# PUT CSV生成仕様

## 概要

`goods_hawb` テーブルから出荷データを抽出し、日本郵便向けEDI連携用CSV（DENFD：発送確定データ）を生成する。  
生成したCSVは `work/put_outbox/` に配置し、SFTPでJPサーバへ送信する。

参照仕様書：出荷データレイアウト仕様書 Ver 4.04（日本郵便株式会社、2021-05-11）  
マッピング定義：出荷データレイアウト仕様書V3_マッピング済み

---

## ファイル形式

| 項目 | 値 | 根拠 |
|---|---|---|
| フォーマット | CSV形式テキストファイル | 仕様書 2.(1) |
| 文字コード | UTF-8（BOMなし） | 仕様書 2.(2) |
| 改行コード | CRLF | 仕様書 2.(3) |
| 区切り文字 | カンマ `,` | 仕様書 2.(4) |
| 囲み文字 | 原則不要（値にカンマを含む場合は `"` で囲む） | 仕様書 2.(5) |
| ヘッダ行 | なし（データ行のみ出力） | 仕様書準拠 |

### 禁則文字（値に含めてはならない文字）

`"` ダブルクォーテーション、`,` カンマ、`\0` NULL、`\t` 水平タブ、`\v` 垂直タブ、`\n` LF、`\r` CR

## 抽出条件

```sql
SELECT *
FROM goods_hawb
WHERE is_delete = 0
  AND hawb_status IN (...)   -- ※確認事項参照
ORDER BY id ASC
```

確認事項: `goods_hawb.hawb_status` の抽出対象値・送信後の更新値を確認（下記「残確認事項」参照）

## 送信後の処理

送信成功後、`work/put_outbox` からローカルファイルを削除し、`goods_hawb.hawb_status` を更新する（※確認事項参照）。

### `hawb_status` の更新（送信成功時）

```sql
UPDATE goods_hawb
SET hawb_status = ?,      -- ※確認事項参照
    update_time = NOW()
WHERE id IN (送信対象のIDリスト)
```

## 残確認事項

| # | 項目 | 優先度 |
|---|---|---|
| 1 | `goods_hawb.hawb_status` の抽出対象値（どの値のレコードを送信するか） | 高 |
| 2 | `goods_hawb.hawb_status` の送信後更新値・更新要否 | 高 |
| 3 | No.19/20（お届け希望年月日・時間帯）の対応カラム | 中 |
| 4 | No.30/31（発送会社コード・発送局コード）の要否（全件同じ局なら固定値設定も可） | 中 |
| 5 | 抽出条件の絞り込み（日付範囲・`belong_to`・`transportation_type` 等） | 中 |
