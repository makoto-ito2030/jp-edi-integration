# PUT CSV生成仕様

## 概要

`goods_hawb` テーブルから出荷データを抽出し、日本郵便向けEDI連携用CSV（DENFD：発送確定データ）を生成する。  
生成したCSVは `work/put_outbox/` に配置し、SFTPでJPサーバへ送信する。

- 参照仕様書：出荷データレイアウト仕様書 Ver 4.04（日本郵便株式会社、2021-05-11）
- マッピング定義：出荷データレイアウト仕様書V5

---

## ファイル形式

| 項目 | 値 | 根拠 |
|---|---|---|
| フォーマット | CSV形式テキストファイル | 仕様書 2.(1) |
| 文字コード | UTF-8（BOMなし） | 仕様書 2.(2) |
| 改行コード | CRLF | 仕様書 2.(3) |
| 区切り文字 | カンマ `,` | 仕様書 2.(4) |
| 囲み文字 | 原則不要（値にカンマを含む場合は `"` で囲む） | 仕様書 2.(5) |
| ヘッダ行 | なし（データ行のみ出力） | 仕様書準拠 |

### 禁則文字（値に含めてはならない文字）

`"` ダブルクォーテーション、`,` カンマ、`\0` NULL、`\t` 水平タブ、`\v` 垂直タブ、`\n` LF、`\r` CR

## 抽出条件

```sql
SELECT g.*
FROM goods_hawb g
-- goods_hawb_extにレコードがない場合も対象に含める
LEFT JOIN goods_hawb_ext e ON g.hawb_no = e.hawb_no
WHERE (
    -- ゆうパック対象の絞り込み
    (g.tracking_no LIKE '1234%')
    OR (g.tracking_no IS NULL AND g.shipping_club = 'ゆうパック')
)
AND g.customs_permit_time IS NOT NULL  -- 通関許可済み
AND g.move_out_time IS NOT NULL        -- 搬出済み
AND g.is_delete = 0                    -- 有効データのみ
AND (
    e.jp_download IS NULL  -- goods_hawb_extのレコード自体が存在しない（未送信）
    OR e.jp_download = 0   -- レコードはあるが未送信
)
ORDER BY g.id ASC
```

## 送信後の処理

送信成功後、`work/put_outbox` からローカルファイルを削除し、`goods_hawb_ext.jp_download` を `1` に更新する。
`goods_hawb_ext` にレコードが存在しない場合はINSERT、存在する場合はUPDATEする（バルク化は実装時に検討）。

```sql
-- レコードが存在しない場合
INSERT INTO goods_hawb_ext (hawb_no, jp_download, create_time, update_time)
VALUES (?, 1, NOW(), NOW())

-- レコードが存在する場合
UPDATE goods_hawb_ext
SET jp_download = 1, update_time = NOW()
WHERE hawb_no = ?
```
